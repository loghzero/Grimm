# Hollow Knight

Este projeto é um site inspirado em Hollow Knight, que fiz para reunir algumas das partes do jogo que eu gosto.
A ideia do site é apresentar esses elementos de uma forma visual e interessante.

## Sobre o site

O site faz uma breve introdução pouco sobre o jogo e depois separa alguns temas que considero importantes, são eles:
- a exploração de Hallownest;
- algumas boss fights marcantes;
- a arte do jogo e o visual das áreas;
- a trilha sonora.

## Interatividade

Parte do meu projeto foi tentar deixar a navegação mais interessante com pequenas interações.
As palavras em cinza ao longo do site têm algum tipo de interação.

Alguns exemplos:
- tópicos que levam para outras partes da página;
- nomes de bosses que mostram imagens;
- nomes de locais que mostram imagens;
- links e elementos que mudam visualmente.

## Objetivo do projeto

Fiz esse projeto porque gosto de Hollow Knight e também porque quero aprender programação.
